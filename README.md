# status-check-v1
A lightweight status checker inspired by Tsewang Bhutia with a little bit of Riad magic

So the brains behind this project was essentially Tsewang, but I thought it was missing something.
It's currently a yellow pages for status checkers (which is totally fine if you don't want to google it and have it open as a reference page!)
I felt that it could have a touch more functionality.. so I reverse engineered it!

The HTML and CSS were super easy to recreate.. I also added some javascript functionality to call statuses built into browsers (currently github and cloudflare)
I think that this a great v-1 and that v-1 is complete and I'll let it live as it's own repository. I would like to create v-2, but since v-2 is a WIP 
and this is a technically finished product, I'll let v-2 live in a separate repository!

thank you, Tsewang!
